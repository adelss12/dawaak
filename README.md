# افهم دواءك — dawaak

صوّر عبوة أي دواء أو اكتب اسمه، فيقرأ البرنامج الصورة عبر Gemini من Google ويعرض ملخصاً عربياً مبسطاً: المادة الفعالة، الاستخدامات، طريقة الاستخدام، الجرعات المعتادة، الأعراض الجانبية، علامات الخطر، الاحتياطات، التداخلات، الحمل والرضاعة، والحفظ. ويمكن طرح أسئلة إضافية عن الدواء نفسه.

> للتثقيف الشخصي فقط، ولا يغني عن الطبيب أو الصيدلي.

## التشغيل

افتح https://adelss12.github.io/dawaak/ وضع مفتاح Gemini المجاني (من https://aistudio.google.com/apikey) مرة واحدة. يُحفظ المفتاح والسجل على الجهاز فقط.

## الملفات

- `index.html` — الواجهة
- `app.js` — المنطق والاتصال بـ Gemini (يختار أحدث نموذج Flash متاح تلقائياً)
