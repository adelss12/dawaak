# افهم دواءك — dawaak

تطبيق عربي مبسط يساعد المستخدم على فهم المعلومات الأساسية عن الدواء بلغة واضحة بعد رفع صورة العبوة أو كتابة اسمها.

> المشروع تثقيفي فقط، ولا يقدّم تشخيصاً أو وصفة طبية ولا يغني عن استشارة الطبيب أو الصيدلي.

## التشغيل المباشر

افتح ملف `index.html` في المتصفح.

## التطوير

```bash
npm install
npm run dev
```

## إنشاء نسخة التشغيل

```bash
npm run build
```
